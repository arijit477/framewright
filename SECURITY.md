# Security Policy

Framewright processes untrusted media files in the browser, so parser and decoder issues
matter to us.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository. We aim to acknowledge reports within 72 hours.

## Supported versions

Only the latest release on `main` receives fixes during the 0.x series.
