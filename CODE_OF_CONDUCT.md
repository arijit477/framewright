# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and welcoming. Assume good intent.
- Give and accept constructive feedback gracefully.
- No harassment, personal attacks, or discriminatory language, in any project space.

## Reporting

Report unacceptable behaviour privately to the maintainers at **conduct@your-domain.example**
(maintainers: replace this address before publishing). All reports are reviewed promptly and
handled confidentially. Maintainers may remove, edit or reject contributions, or ban
participants, for behaviour that violates this code.
